💰 MyFinancialCRM - Banka ve Fatura Yönetim Sistemi
Bu proje, C# ve Entity Framework kullanılarak geliştirilmiş banka hareketleri, faturalar ve finansal verilerin yönetildiği bir masaüstü uygulamasıdır. SQL veritabanı ile entegre çalışarak kullanıcıların banka bakiyelerini, faturalarını ve finansal hareketlerini takip etmelerini sağlar.

🛠️ Kullanılan Teknolojiler

🔹C# (.NET Windows Forms)

🔹Entity Framework

🔹SQL Server

🔹Chart Kütüphanesi (Grafiksel veri görselleştirme için)
